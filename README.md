✋ Real-Time Hand Tracking System – Part 1

A real-time Hand Tracking application built using **HTML, CSS, JavaScript, and MediaPipe Hands**. The project uses a webcam to detect and track hand movements, identify finger positions, and display tracking information in real time.

Features

- Real-time hand detection using webcam.
- Tracks up to 2 hands simultaneously.
- Detects 21 hand landmarks.
- Displays each finger with a different color.
- Counts the number of raised fingers.
- Displays the number of detected hands.
- Shows real-time FPS (Frames Per Second).
- Interactive visual representation using HTML Canvas.

Technologies Used

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands
- HTML5 Canvas API
- WebRTC (getUserMedia)

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Click **Start Camera**.
5. Allow webcam permission.
6. Show your hand in front of the camera.
